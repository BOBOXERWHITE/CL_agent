# 19 合规与隐私安全

#### 关键词
`PIPL / 个保法 / DSL / 数据安全法 / CSL / 网络安全法 / GDPR / CCPA / PCI-DSS / 数据出境 / 跨境传输 / 安全评估 / 标准合同 / SCC / 等级保护 / 等保 / DPIA / 公安境外人员临时住宿登记 / 公安备案 / KYC / AML`

> 本文以 2026 年 4 月有效的中国 / 欧盟 / 美国主要法规为准。具体合规以企业法务、当地律师、监管最新文件为准。

## 1. 中国境内适用法律法规

### 1.1 个人信息保护法 (PIPL，2021-11-01 实施)

| 条款 | 摘要 |
| --- | --- |
| 第 4 条 | 个人信息：以电子或者其他方式记录的与已识别或可识别的自然人有关的各种信息 |
| 第 13 条 | 处理个人信息须取得**单独同意** / 履行合同 / 法定职责等 |
| 第 17 条 | 告知义务（处理目的、方式、种类、保存期限） |
| 第 28 条 | 敏感个人信息（身份证、生物识别、宗教、特定身份、医疗健康、金融账户、行踪轨迹、不满 14 周岁未成年人）必须**单独同意** |
| 第 38 条 | 跨境传输：通过国家网信部门安全评估 / SCC / 认证 |
| 第 51 条 | 处理者义务（合规机构、培训、审计） |
| 第 55 条 | DPIA（个人信息保护影响评估） |
| 第 66 条 | 行政处罚最高 5,000 万 RMB 或 5% 上年营业额 |

### 1.2 数据安全法 (DSL，2021-09-01)

- 数据分级：核心 / 重要 / 一般
- 重要数据出境需安全评估
- 数据安全审查制度

### 1.3 网络安全法 (CSL，2017-06-01)

- 关键信息基础设施 (CII) 安全保护
- 网络运营者义务
- 用户实名制
- 漏洞 / 事件报告
- 等级保护制度（等保 2.0，从 1 级到 5 级）

### 1.4 旅游住宿业相关行政法规

```
- 《旅游饭店行业规范》
- 《旅馆业治安管理办法》
- 《公安部关于在全国旅馆业开展持证上岗工作的通知》
- 《境外人员临时住宿登记表》(公安部要求)
- 《增值税专用发票使用规定》
- 《关于全面推开营业税改征增值税试点的通知》
```

## 2. 关键合规义务

### 2.1 出行人身份核验

| 出行人 | 必采字段 | 备注 |
| --- | --- | --- |
| 中国大陆居民 | 姓名 + 身份证号 + 手机 | 实名 |
| 港澳居民 | 港澳居民来往内地通行证 | 等同身份证 |
| 台湾居民 | 台湾居民来往大陆通行证 | 同上 |
| 外籍 | 护照 + 签证 + 国籍 + 出生日期 | 入住时复印 + 公安备案 |
| 未成年人（≤14 岁） | 父母姓名 + 监护证明 | 高敏感 |

### 2.2 公安境外人员临时住宿登记

```
中国大陆所有可接待外籍客人的酒店必须：
[1] 取得"涉外资质"
[2] 在外籍客人入住后 24 小时内向辖区公安备案
[3] 提交：护照号、签证号、入境日期、国籍、出生日期、入住房号
[4] 出店 24 小时内告知公安
```

> 差旅平台为外籍员工预订时必须显示"涉外资质"标记，否则订单失败 / 延迟。

### 2.3 实名登记（中国大陆）

```
《旅馆业治安管理办法》第六条：
"旅馆接待旅客住宿必须登记。"
登记内容：姓名、性别、年龄、籍贯、住址、身份证号、来何处、何处去、入住日期等。
```

差旅平台必须在 PMS 入住时核验：

- 出行人本人到店（部分酒店要求"现场人脸 + 身份证"）
- 代订时需"被代订人书面授权"

## 3. 跨境数据传输

### 3.1 中国出境（向境外传输）

| 路径 | 适用 | 周期 |
| --- | --- | --- |
| 国家网信办安全评估 | CII / 大量个人信息 | 6–12 月 |
| 标准合同 (SCC) | 一般场景 | 备案制，1–3 月 |
| 个人信息保护认证 | 跨集团内部转移 | 6 月 |

差旅平台典型跨境场景：

```
- 海外差旅订单数据 → 海外酒店 PMS / 集团 CRS
- 海外信用卡支付 → 收单行 / 卡组织
- 海外 OTA / GDS 接入
- 全球员工差旅平台（多国）数据汇总
```

合规建议：

```
1. 行程信息（必须的）：实施 SCC + 备案
2. 敏感个人信息（身份证 / 护照）：单独同意
3. 信用卡：通过 PCI-DSS 合规支付网关
4. 企业内部数据：同集团内部 BCR / 认证
```

### 3.2 GDPR (欧盟)

适用：

- 在欧盟境内 / 收集欧盟数据主体的个人数据
- 中国差旅平台处理欧盟员工差旅 / 接待欧盟客人

主要要求：

| 要求 | 摘要 |
| --- | --- |
| 法律基础 | 6 项之一（同意、合同、法定、关键利益、公共任务、合法利益） |
| 数据主体权利 | 知情、查阅、修改、删除、限制处理、可携带、反对 |
| 数据保护官 (DPO) | 大规模处理 |
| DPIA | 高风险处理 |
| 数据泄露通知 | 72 小时内 |
| 罚款 | 最高 EUR 2,000 万 或全球营收 4% |

### 3.3 CCPA / CPRA (加州)

- 适用：加州居民个人数据
- 权利：知情、删除、不出售
- 罚款：USD 2,500 / 故意 USD 7,500 / 单次

## 4. PCI-DSS (支付卡行业数据安全标准)

### 4.1 等级

| Level | 卡交易量 | 合规要求 |
| --- | --- | --- |
| Level 1 | >600 万 / 年 | 第三方 QSA 现场审计 |
| Level 2 | 100–600 万 | 自评估 + ASV 扫描 |
| Level 3 | 2 万–100 万 | 自评估 + ASV 扫描 |
| Level 4 | <2 万 | 视卡组织 |

### 4.2 12 项核心要求

```
1. 安装并维护防火墙
2. 不使用厂商默认密码 / 安全参数
3. 保护已存储的持卡人数据（不存 CVV，PAN 加密）
4. 跨网传输持卡人数据须加密 (TLS)
5. 反恶意软件
6. 安全开发与系统维护
7. 按 need-to-know 限制访问
8. 唯一身份 + 强密码
9. 物理访问控制
10. 监控所有访问
11. 定期测试系统与流程
12. 维护信息安全策略
```

### 4.3 主要不合规风险

```
- 直接存储 CVV → 立即整改
- 卡号明文存储 → 必须 token 化
- 跨境传输无加密 → 升级 TLS
- 第三方支付通道未审计 → 委托方需选 PCI 合规通道
- 日志含卡号 → 日志脱敏
```

## 5. 知情同意与隐私通知

差旅平台必须在以下时点弹出明确的隐私通知：

| 触发 | 内容 |
| --- | --- |
| 首次注册 | 处理目的 / 范围 / 期限 / 第三方 |
| 录入护照 / 身份证 | 单独同意（PIPL 第 28 条） |
| 跨境传输 | 单独同意 + SCC 概要 |
| Cookie / 行为埋点 | 单独同意 |
| 推送营销 | 单独同意 |
| 与父母 / 监护人共享未成年人数据 | 监护人同意 |

## 6. 安全控制（应用层）

### 6.1 身份认证

```
- SSO + MFA
- 强密码策略：≥12 字符，含大小写 + 数字 + 符号
- 失败 5 次锁定 30 分钟
- 会话超时 30 分钟
- 关键操作（出单 / 支付）二次确认
```

### 6.2 访问控制

```
- 最小权限原则 (PoLP)
- RBAC + ABAC
- 多租户隔离（tenant_id 行级安全 RLS）
- 敏感字段单独权限
- 定期权限复核（季度）
```

### 6.3 加密

| 数据 | 加密方式 |
| --- | --- |
| 静态 | AES-256 |
| 传输 | TLS 1.2+ |
| 数据库 | 透明加密 (TDE) |
| 密钥 | KMS（硬件 / 软件） |
| 备份 | 加密 + 异地 |

### 6.4 日志与审计

```
- 所有敏感操作必记审计日志（who/what/when/where/result）
- 不可篡改（追加式 / 区块链 / WORM）
- 保留期 ≥6 个月（PIPL 第 11 条）/ 视行业（金融 ≥5 年）
- 登录日志单独存
- 异常监控 + 实时告警
```

### 6.5 数据脱敏

```
- 测试 / 开发环境禁用真实生产数据
- 必须脱敏：身份证 / 护照 / 手机 / 邮箱 / 银行卡
- 脱敏算法：截断 / 哈希 / 替换
```

## 7. 风险管理

### 7.1 数据泄露事件响应 (IR)

```
[T+0]    检测 (SIEM / 用户报告)
[T+1h]   评估范围 + 影响
[T+2h]   阻断 + 取证
[T+24h]  通知监管（GDPR 72h；中国"立即"）
[T+72h]  通知数据主体（重大风险）
[T+1w]   根因分析
[T+1m]   整改 + 复盘
```

### 7.2 第三方风险（供应商管理）

```
- 入网评估：合规 / 数据安全 / 业务连续性
- 合同含数据保护条款 (DPA)
- 年度审计
- SOC 2 / ISO 27001 / 等保 2 三级
- 退出条款（数据返还 + 销毁证明）
```

## 8. 内部合规岗（差旅运营）

```
- 数据保护官 (DPO) — 1 名（≥1000 人企业）
- 信息安全官 (CISO)
- 合规官 (Compliance Officer)
- 隐私管理团队 — 处理数据主体请求
- 风险审查会 — 季度
```

## 9. 关键差旅场景的合规风险

| 场景 | 风险 | 缓释 |
| --- | --- | --- |
| 海外出行人入住中国大陆 | 公安备案 | 选涉外酒店 |
| 中国员工出境差旅 | 数据出境 | SCC + 单独同意 |
| 客户接待（高净值 / 政要） | 行踪轨迹（敏感） | 严格内部访问控制 |
| 集团内 PA / 助理代订 | 代订授权 | 书面授权 |
| 紧急救援数据 | 健康（敏感） | 仅紧急场景 |
| 大规模差旅数据分析 | 去标识化 | 匿名化 / 聚合 |
