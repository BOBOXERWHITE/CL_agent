## 5. 差旅政策与会员体系

### 5.1 公司应允许员工保留个人会员积分？

行业惯例：

- 大企业（外企）：通常允许员工保留个人积分作为差旅福利
- 中型企业：部分允许，部分要求积分归公司
- 国企 / 央企：多数要求积分归公司或不允许个人累积
- 项目客户接待：积分归公司（通过公司会员账户）

差旅平台支持配置：`points_ownership = personal | company | hybrid`

### 5.2 状态保留

- 集团多数有"年度间夜达成 = 次年保留状态"
- 部分集团允许"购买间夜"或"积分保级"
- 差旅政策通常不阻止员工"集中入住同一品牌保级"，但要求 ≤ 协议价 / BAR 限额

### 5.3 集团专属促销

## 8. 兑换技巧（非政策推荐，仅技术性说明）

```
1. Marriott "5th Night Free" 仅作用于积分兑房，且需连续 5 晚同酒店
2. Hilton "5th Night Free" 同上
3. Hyatt "4th Night Free"（积分兑房）
4. Hyatt 7 类酒店在 Cat 1–4 区间，性价比最佳
5. Accor 1 € = 1 €，可直接抵房费，不挑酒店
6. 华住积分等价于现金 5–10 折（视活动）
```

## 9. 会员卡欺诈与合规风险

```
- 假会员 / 假卡：高级会员卡需在集团 APP 实时核验
- 状态匹配：Hyatt Status Match、Hilton Status Match 渠道
- 公司报销不能含"积分价值"：积分非现金
- 升级礼遇不应被酒店反向收费
- 同一员工跨部门刷间夜保级 → 风险（违规）
```
