# 20 SLA、KPI 与运营指标

#### 关键词
`SLA / KPI / RevPAR / ADR / OCC / TRevPAR / GOPPAR / NPS / CSAT / 出单成功率 / Walk Rate / 客诉率 / 月结对账 / 协议覆盖率 / 数据看板`

## 1. 行业核心指标

### 1.1 收益指标（酒店侧）

| 指标 | 公式 | 含义 |
| --- | --- | --- |
| ADR | 客房收入 / 已售房晚 | 平均房价 |
| OCC | 已售房晚 / 可售房晚 | 出租率 |
| RevPAR | ADR × OCC = 客房收入 / 可售房晚 | 关键指标 |
| TRevPAR | 总收入 / 可售房晚 | 含餐饮 / 宴会 |
| GOPPAR | 营业毛利 / 可售房晚 | 含成本控制 |
| ALOS | 房晚 / 入住次数 | 平均住宿晚数 |
| ARI | 自身 ADR / 市场 ADR | 价格指数 |
| MPI | 自身 OCC / 市场 OCC | 占有指数 |
| RGI | 自身 RevPAR / 市场 RevPAR | 营收指数 |

### 1.2 差旅平台 KPI

| 指标 | 公式 | 目标 |
| --- | --- | --- |
| 协议覆盖率 | 协议价订单数 / 总订单数 | ≥70% |
| 协议遵从率 | 差标内订单数 / 总订单数 | ≥95% |
| 平均节省率 | (BAR − 实付) / BAR | 行业 8–18% |
| 政策违规率 | 违规数 / 总订单 | ≤5% |
| 出单成功率 | 成功 / (成功 + 失败) | ≥99% |
| Walk Rate | Walk 数 / 入住数 | ≤2% |
| 客诉率 | 客诉数 / 入住数 | ≤1% |
| NPS | 推荐 % − 贬损 % | ≥40 |
| CSAT | 平均满意度 | ≥4.5 / 5 |
| 月结对账时效 | T + N 完成 | T+5 |
| 发票合规率 | 一次过率 | ≥98% |
| 报销时效 | 提交至打款 | 中位 ≤7 工作日 |

## 2. SLA 模板（与酒店 / 集团）

```
[1] 出单确认时效
    - 直连：实时 (≤5 秒)
    - GDS / OTA：实时 (≤30 秒)
    - 批发商：异步 ≤30 分钟

[2] 修改 / 取消
    - 在免费窗口内：实时
    - 罚金扣款：实时

[3] 入住保障
    - Walk Rate ≤2%（年度）
    - Walk 时同档酒店 ≤3km / 第一晚全免

[4] 月结
    - 月底 T+3 出账
    - T+10 对账完成
    - T+30 付款

[5] 客诉响应
    - L1 ≤2 小时
    - L2 ≤1 小时
    - L3 ≤30 分钟

[6] 数据接口
    - 库存推送 ≤5 分钟
    - 价格推送 ≤5 分钟
    - 接口可用性 ≥99.9%
```

## 3. SLA 模板（差旅平台对内）

```
[1] OBT 可用性 ≥99.5%
[2] 搜索响应 ≤2 秒 (P95)
[3] 出单接口 ≤5 秒 (P95)
[4] 客户工单首响 ≤30 分钟
[5] 紧急 24/7 通话接通 ≤30 秒
[6] 申诉处理 ≤48 小时
[7] 数据同步延迟 ≤5 分钟
[8] 灾备恢复 RTO ≤4 小时 / RPO ≤15 分钟
```

## 4. KPI 数据看板（建议页面）

### 4.1 总览页

```
- 当月差旅总额 (含税)
- 月环比 / 同比
- 协议覆盖率
- 协议遵从率
- 出单成功率
- 客诉率
```

### 4.2 城市与酒店

```
- TOP 10 城市消费
- TOP 20 酒店消费
- 各酒店满意度 / 客诉率
- 各酒店 Walk Rate
- 协议价 vs 市场 BAR
```

### 4.3 渠道分析

```
- 各渠道订单数 / 金额
- 各渠道平均价格
- 各渠道客诉率
- 各渠道发票合规率
```

### 4.4 用户行为

```
- 出行人差旅频次分布
- 提前预订时间分布
- 取消率分布
- 节省率分布
```

### 4.5 财务

```
- 月结对账时效
- 应收 / 应付
- 退款时效
- Chargeback 率
```

## 5. KPI 与 RFP / 续签的关联

```
RFP 谈判筹码：
- 历史 ADR 偏离
- 协议覆盖率不足 → 抑制扩量
- 客诉率高 → 罚则加严
- Walk Rate 高 → 退出协议
```

## 6. 数据采集与口径

差旅 KPI 的口径必须与财务 / HR / 业务对齐。

```
[1] "差旅订单"定义：必须以"出单成功"且非"已取消"为基准
[2] "实付金额"定义：含税 + 强制项 (Resort Fee)
[3] "退款"定义：发生退款不应纳入"消费"
[4] "客诉"定义：进入工单系统的（不含未升级口头反馈）
[5] "节省率"基准：BAR 价 (出单时点快照)
[6] "Walk"定义：实际入住与原预订酒店不一致
```

## 7. 实时监控告警

```
[业务]
- 单日出单失败率 >1% → 告警
- 单日 Walk 数 >5 → 告警
- 单日客诉 >10 → 告警
- 单笔订单 >RMB 10 万 → 告警
- 协议价命中率连续 7 日 <60% → 告警

[技术]
- 接口 P95 延迟 >2× 基线 → 告警
- 错误率 >1% → 告警
- 直连掉线 >3 次 → 告警
- 库存同步延迟 >10 分钟 → 告警
- 网络出境流量异常 → 告警

[财务 / 合规]
- 月结对账延迟 >3 日 → 告警
- 发票拒收率 >5% → 告警
- 跨境数据异常 → 告警
- PII 大批查询 → 告警
```
