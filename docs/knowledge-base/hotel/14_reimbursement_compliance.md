# 14 报销与差旅政策合规

#### 关键词
`差旅政策 / 差标 / 报销 / 凭证 / 发票合规 / 超标 / 审批 / 政策违规 / 抽查 / 审计 / 同行同住 / 间夜 / per diem / 差旅补贴 / 城市档`

## 1. 差旅政策的基本结构

```
[1] 政策目标          ← 控成本、保合规、保员工体验
[2] 政策适用范围      ← 哪些员工 / 哪些差旅
[3] 出行人级别        ← 普通员工 / 经理 / 总监 / 副总 / 高管
[4] 城市档            ← A 类 / B 类 / C 类
[5] 差标矩阵          ← 级别 × 城市 = 房费 / 星级 / 餐补 / 交通
[6] 预订渠道          ← 必须走 OBT / TMC
[7] 发票要求          ← 项目 / 抬头 / 税号
[8] 审批流程          ← 超标 / 例外
[9] 报销流程          ← 时效 / 资料 / 拒收
[10] 违规处理         ← 警告 / 扣减 / 处分
```

## 2. 差标矩阵示例

> 以下矩阵为示例，不构成具体公司政策。

### 2.1 城市档分类

```

E 档 (海外其他): 视目的国生活成本
```

## 3. 报销前提与必备凭证

### 3.1 必备凭证

| 凭证 | 数量 | 备注 |
| --- | --- | --- |
| 发票 | 1 张 | 抬头、税号、项目 |
| 入住账单 (Folio) | 1 份 | 酒店出 |
| 行程审批单 | 1 份 | OBT 自动生成 |
| 出差申请表 | 1 份 | 系统留底 |
| 客户接待说明 | 视情况 | 接待 |
| 项目编号 | 必填 |  |
| 成本中心 | 必填 |  |

### 3.2 可选凭证

```
- 邮件 / 飞书 / 钉钉沟通记录（佐证公务）
- 客户名片 / 会议纪要
- 出租车 / 高铁票（同段）
- 担保信用卡水单
```

## 4. 政策违规分类

| 违规类型 | 严重度 | 处罚 |
| --- | --- | --- |
| 房费超标 ≤10% | 轻 | 警告，超额自付 |
| 房费超标 11–30% | 中 | 主管审批 + 超额自付 |
| 房费超标 >30% | 重 | HR 审批 + 全额自付 |
| 星级超档 | 中 | 总监审批 |
| 不走 OBT / TMC | 中 | 主管审批 + 失去协议价 |
| 预付不可退 + 取消 | 中 | 全责自付 + 备案 |
| 套餐含 SPA / 高尔夫 | 重 | 不予报销 |
| 个人陪同入住 | 重 | 不予报销 + 警告 |
| 私人消费混入差旅 | 重 | 拒报 + 处分 |
| 假发票 / 重复报销 | 极重 | 解除合同 + 移交司法 |

## 5. 同行同住 (Share Room)

| 场景 | 政策 |
| --- | --- |
| 同性 + 同部门 + 客户接待 | 视协议（多数允许，节省成本） |
| 异性 + 同部门 | 一般不允许 |
| 培训 / 团建 | 允许 |
| 出差人 + 配偶 / 家属 | 自费部分自担 |

> 差旅平台必须支持"同行同住"工单，按"实际入住人数 / 房间数"分摊房费。

## 6. 出差补贴 (Per Diem)

补贴模式两类：

| 模式 | 含义 |
| --- | --- |
| 实报实销 (Actuals) | 凭票报销，无补贴 |
| 标准定额 (Per Diem) | 不凭票，按目的地标准给定额 |
| 混合 | 住宿凭票 + 交通伙食按定额 |

差标定额示例（仅示例）：

| 城市档 | 早餐 | 午餐 | 晚餐 | 杂费 | 合计 |
| --- | --- | --- | --- | --- | --- |
| A 档 | 50 | 80 | 100 | 30 | 260 |
| B 档 | 40 | 60 | 80 | 20 | 200 |
| C 档 | 30 | 50 | 60 | 20 | 160 |

> 定额制下：含早酒店应**扣减"早餐补贴"**避免双重报销。

## 7. 抽查与审计

### 7.1 自动抽查触发器

```
- 单日报销 > RMB 5,000
- 当月报销总额 > RMB 30,000
- 同员工同酒店年内 > 10 次
- 节假日入住（疑似私人）
- 入住非差旅城市
- 周五入住次日离店（疑似 weekend leisure）
- 票据时间 vs 行程时间错位
- 多张发票总额 = 已报销总额
- 重复发票号
- 抬头错误
```

### 7.2 人工抽查比例

```
L1–L4: 5%
L5–L6: 10%
L7+:  100%
异常报销: 100%
```

### 7.3 审计留存

| 数据 | 保留期 |
| --- | --- |
| 发票电子件 | 10 年 |
| 行程审批 | 10 年 |
| 入住账单 | 10 年 |
| 政策变更日志 | 终身 |
| 协议合同 | 合同期 + 10 年 |

## 9. 高频拒报场景

| 场景 | 拒报理由 | 政策建议 |
| --- | --- | --- |
| 项目编号缺失 | 不可入账 | 出差前必须录入项目 |
| 抬头错误 | 不合规 | OBT 默认带公司抬头 |
| 含 SPA 套餐 | 私人消费 | 套餐拆分 |
| 周末连续入住 | 疑似休假 | 公务证明 |
| 节假日入住 | 疑似私人 | 公务证明 |
| 同行 + 异性 | 政策禁止 | 双间订房 |
| 加床 / 多人入住 | 自费 | 自费另开 |
| 迷你吧 / 电影 | 自费 | 拆分账单 |
| 钟点房 | 政策禁止 | 不报 |
| 发票项目"会议费" | 项目错配 | 重开 |
| 跨年发票 | 5/31 后 | 上一年清账 |

## 10. 政策强制走 OBT / TMC

理由：

```
1. 价格更优（协议价 / BAR 谈判）
2. 数据全（合规 / KPI / 数据看板）
3. 安全（紧急联络 / 24h 协助）
4. 政策合规自动化
5. 财务对账自动化
6. 风控（员工双订防护、重复报销）
```

例外允许场景：

```
- OBT 内无该酒店（罕见城市）
- OBT 系统故障 + 时效紧急
- 客户指定接待酒店（VIP）
- 不可抗力
```

例外需提前 / 事后审批，且要求"原始凭证 + 比价证明 + 报销补充说明"。

## 11. 节假日 / 周末特别政策

| 情形 | 政策 |
| --- | --- |
| 周五入住、周一离店 | 必须公务证明 |
| 周日入住但周一才有会议 | 多数公司允许（避免周一一早赶路） |
| 春节 / 国庆 / 五一 | 默认禁止，特殊审批 |
| 客户邀请观赛 / 庆典 | 视为业务招待，不计差旅 |
| 客户拜访 + 个人延伸 | 公务部分计差旅，私人自费 |

## 12. ESG / 可持续差旅

部分企业要求：

```
- 优先选择有 LEED / GreenKey / EarthCheck 认证酒店
- 优先选择 ESG 评级高的集团（Marriott、Hilton、IHG 均发布年度报告）
- 鼓励连住，减少酒店换洗 / 排放
- 鼓励本地酒店，减少长途
- 报告每段差旅碳排放（HCMI 1.1 / GHG Protocol）
```

差旅平台应在选品时给出 `co2_per_night_kg`、`green_certification` 字段。

## 13. 决策表（员工自助）

| 我的场景 | 推荐做法 |
| --- | --- |
| 同档酒店有协议价 | 必选协议价 |
| 协议价 + BAR 价差 ≤5% | 选协议（保会员积分） |
| 协议价 > BAR 价 | 选 BAR + 上报采购 |
| 入住不超差标 | 自助下单 |
| 超差标 ≤20% | 提交主管审批 |
| 超差标 >20% | 提交总监 / HR |
| 早鸟价不可退 + 行程未确定 | 选 BAR |
| 早鸟价 + 行程确定 | 选早鸟（可省 15%） |
| 客户慰问 / 高端接待 | 走业务招待，不走差旅 |
| 同行同住 | 走"同行同住"工单 |

## 14. 风险点

1. **政策更新滞后**：差旅政策与税法变更，差旅平台需双向校验
2. **超标订单事后审批**：员工先订后审，差旅平台默认"先审后订"
3. **OBT 价格不全**：员工绕过 → OBT 价格库需覆盖 ≥95% 城市
4. **政策歧义**：政策文档语言不清晰 → 知识库统一术语
5. **审批人离职**：审批链路需自动 fallback
6. **跨子公司差旅**：母子公司差标不一致，需在 OBT 层细分 tenant
7. **代差旅 / 客户差旅**：客户报销与公司报销混淆，需独立 cost center
