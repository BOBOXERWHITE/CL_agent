# 06 预订全流程 SOP

#### 关键词
`SOP / 预订 / 报价 / 询价 / 担保 / 出单 / 确认 / 入住 / 离店 / 复核 / 修改 / 异常 / 重复订单 / 双订 / 出单失败 / 排房 / Concierge`

## 1. 端到端流程

```
[1] 需求采集 → [2] 政策合规校验 → [3] 询价 / 选品 → [4] 担保确认 → [5] 出单
   ↓                                       ↓
[6] 出单后通知    ←   [7] 入住前 24h 复核    ←   [8] 实际入住 / 异常
                                                 ↓
                                       [9] 离店复核 → [10] 结算 → [11] 报销 → [12] 关单
```

## 2. 阶段 1 — 需求采集

### 2.1 必填字段

| 字段 | 含义 | 校验 |
| --- | --- | --- |
| `tenant_id` | 公司 / 子公司 | 必填 |
| `traveler_id` | 出行人主键 | 必填 |
| `cost_center` | 成本中心 | 必填 |
| `project_code` | 项目编号 | 推荐 |
| `purpose` | 出行目的 | 必填（拜访客户 / 内部会议 / 培训 / 其他） |
| `city` / `geo_id` | 目的地 | 必填 |
| `check_in` | 入住日期 | 必填 |
| `check_out` | 离店日期 | 必填，>check_in |
| `nights` | 住宿晚数 | 自动 |
| `pax_adults` | 成人 | 必填 |
| `pax_children` | 儿童 + 年龄 | 含 ≥1 时填年龄 |
| `room_count` | 房间数 | 必填 |
| `share_room` | 是否合住 | 默认 false |
| `preferred_brand` | 偏好品牌 |  |
| `preferred_hotel` | 偏好酒店 |  |
| `accessibility_required` | 无障碍 | 默认 false |
| `smoking` | 吸烟偏好 | 默认 non_smoking |
| `notes` | 自由备注 |  |

### 2.2 出行人身份核验

- 国内：身份证号 + 手机号
- 港澳台：港澳通行证 / 台胞证号
- 外籍：护照号 + 国籍 + 出生日期
- 出差人 ≠ 实际入住人时，差旅政策需明确"代订规则"

## 3. 阶段 2 — 政策合规校验

### 3.1 决策表（差标 + 城市档）

| 出行人级别 | 城市档 A（北上深广） | 城市档 B（省会） | 城市档 C（地级市） |
| --- | --- | --- | --- |
| 普通员工 | RMB ≤700 / 晚 | RMB ≤500 / 晚 | RMB ≤350 / 晚 |
| 经理 | RMB ≤1,000 / 晚 | RMB ≤700 / 晚 | RMB ≤500 / 晚 |
| 总监 / 高级经理 | RMB ≤1,500 / 晚 | RMB ≤1,000 / 晚 | RMB ≤700 / 晚 |
| 副总 | 不限 + 5 星 | 不限 + 4 星 | 不限 + 3 星 |
| 高管 / 客户接待 | 不限 + 5 星 | 不限 + 5 星 | 不限 + 4 星 |

> 此处仅为示例。具体差标须由企业差旅政策（[14_reimbursement_compliance.md](14_reimbursement_compliance.md)）覆盖。

### 3.2 校验项

| 校验项 | 说明 | 阻断 / 警告 |
| --- | --- | --- |
| 差标超额 | 房价 > 差标 | 警告，需审批 |
| 星级超档 | 高于差标星级 | 警告 |
| 入住日期不合理 | check_in < today / >180d | 阻断 |
| 周末入住 + 公司禁周末差旅 | 视政策 | 警告 |
| 同一员工同日期重复订单 | 双订防护 | 阻断 |
| 同一员工跨城市重叠 | 校验日期 | 警告 |
| 取消政策不可退 + 高金额 | > 差标 50% | 警告 + 二次确认 |
| 协议价资格 | 公司不在白名单 | 阻断 |
| 国家 / 地区限制 | 高风险目的地 | 阻断 + 走风控 |

### 3.3 超标处理路径

```
房价超差标 ≤20%      自助提交理由 → 直属主管审批
房价超差标 20–50%    HRBP / 总监审批
房价超差标 >50%      VP 审批 + CFO 备案
非差标星级           合规岗 / 行政部审批
```

## 4. 阶段 3 — 询价与选品

### 4.1 询价路径优先级

```
1. 协议价 (CRP)               ↓ 命中
2. 集团会员价 (MEMBER)        ↓ 命中
3. BAR + 折扣 (BAR-PROMO)     ↓ 命中
4. BAR
5. 早鸟 / 不可退（仅限行程确定）
6. OTA 公开促销
7. 批发商净价 + 加价（兜底）
```

### 4.2 排序与展示

差旅平台默认排序应基于 **企业偏好得分**，而非价格：

```
score = w1 × 价格分 + w2 × 差标贴合度 + w3 × 协议价 + w4 × 会员积分 +
        w5 × 评价分 + w6 × 距离分 + w7 × 历史满意度 + w8 × 政策合规
```

### 4.3 选品提示

- 同酒店多个房型，按"差标内最优 → 含早 → 评价 ≥4.5"过滤
- 不可退价格在卡片上**强制突出标记**，并显示"取消即损失全额"
- Resort Fee / 城市税 / 服务费应在卡片上分项展示
- 需要发票的：必须默认勾选"开具增值税普通发票"或"专票"

## 5. 阶段 4 — 担保与确认

### 5.1 担保方式选择

| 担保 | 适用 | 备注 |
| --- | --- | --- |
| 公司 BTA / Lodge Card | 长期协议 / 大企业 | 自动结算 |
| 虚拟卡 (VCC) | 散订 / 单次 | 一次性卡号 |
| 个人信用卡 | 散订 + 后续报销 | 出行人垫付 |
| 银行账户挂账 (Direct Bill) | 月结协议酒店 | 需酒店白名单 |
| 现金 / 押金 | 经济型酒店 | 不建议 |
| 信用住 (芝麻信用 / 微信支付分) | 国内 OTA |  |

### 5.2 出单条件检查

```
- 校验会员账号绑定 (避免不积分)
- 校验房型 / 床型可分配 (双订单需确保连通房 / 双间)
- 校验早 / 加床 / 婴儿床
- 校验入住人 vs 担保人是否一致
- 校验客人主习惯 (吸烟 / 楼层 / 安静)
```

## 6. 阶段 5 — 出单

### 6.1 出单成功标志

| 字段 | 值 |
| --- | --- |
| `external_confirmation_no` | 来自 OTA / 集团 / GDS 的确认号 |
| `pms_reservation_id` | 酒店内部预订号（Opera / Marsha / OnQ / Holidex / TARS / HMS） |
| `status` | confirmed / pending / on_request |
| `tx_log_id` | 出单事务 ID |

### 6.2 出单失败常见原因

| 错误码 | 原因 | 处理 |
| --- | --- | --- |
| `RATE_NOT_AVAILABLE` | 价格已变 | 重新询价 |
| `INVENTORY_OUT` | 无房 | 选下一选项 |
| `RESTRICTION_VIOLATION` | CTA / MinLOS 违反 | 改日期 |
| `GUARANTEE_DECLINED` | 卡拒付 | 换支付方式 |
| `DUPLICATE_BOOKING` | 重复订单 | 引导查看现有订单 |
| `CRC_NOT_AUTHORIZED` | 协议价无权限 | 检查公司代码 |
| `TIMEOUT` | 网络超时 | 异步查询确认是否实际出单 |

### 6.3 异步出单 (Async Confirmation)

部分批发商 / 直连存在异步出单：

- 出单时返回 `pending`
- 5–60 分钟内推送最终结果
- 差旅平台必须实现"幂等查询"，根据 `idempotency_key` 防止双订
- 客户侧界面应展示"正在确认（预计 X 分钟）"，不可让客户重提

## 7. 阶段 6 — 出单后通知

### 7.1 必发通知

| 通知 | 时机 | 内容 |
| --- | --- | --- |
| 邮件 / 短信 / 飞书 / 钉钉 | 出单成功后 | 酒店、入住、离店、确认号、酒店电话 |
| 出行人短信 | 入住前 1 日 09:00 | 入住时间提醒、地图、电话 |
| 主管 / 财务通知 | 视政策 | 超标审批、月结挂账提醒 |
| 酒店通知 | 出单后 | Special Request 同步、ETA |

### 7.2 通知字段

```
酒店名称 + 中英对照
地址 + 经纬度 / 高德 ID / 谷歌 Map link
酒店电话（直拨 + 国内 400 / 海外 +nn）
确认号 (external_confirmation_no)
入住日期 / 离店日期 / 入住人
房型 / 床型 / 含早
取消政策（突出"最迟可免费取消时刻"）
担保方式
特殊请求
价格（含税合计 + 入店还需付的强制项）
TMC 24h 服务热线
```

## 8. 阶段 7 — 入住前复核 (T-24h)

### 8.1 自动校验

- ETA 是否提供（迟到 18:00 后未提供需短信提醒）
- 高风险目的地：天气、防疫、签证
- 确认号校验：通过 GDS / 直连重新查询，防止酒店端漏录
- 前一日酒店是否仍在营业（罕见但发生：临时停业 / 火灾）

### 8.2 出行人推送

```
明天入住提醒 + 早入早出沟通 + 酒店地址 + 联络人
```

## 9. 阶段 8 — 实际入住 / 异常

### 9.1 现场所需

- 身份证 / 护照
- 信用卡（即使预付，仍可能预授权杂费）
- 公司差旅函（部分酒店要求，挂账时尤其）
- 协议价证明（口头说"公司代码"或印有 `CRC` 的协议函）

### 9.2 异常分类

| 异常 | 处理路径 |
| --- | --- |
| 酒店无入住记录 | 出示确认号 → TMC 协助 → 强制兑现 / Walk |
| 酒店分配错误房型 | 现场升级 / 换房，事后扣减 |
| 酒店要求加价 | 拒绝 → TMC 协助 → 投诉 |
| 酒店关闭 | TMC 重新安排同档酒店 + 全额退款 |
| 酒店要求出行人付全款 | 与原本协议担保不符 → TMC 协助 |

### 9.3 现场服务保障

- TMC 24/7 热线：拨打、微信、飞书机器人
- 高管 / VIP：白名单走"专属经理"通道，5 分钟内响应

## 10. 阶段 9 — 离店复核

- 复核账单：房费、税费、Resort Fee、杂费
- 复核杂费拆分：私人消费需另开（不可计入差旅）
- 复核含早份数（与协议一致）
- 退还押金 / 解除预授权
- 索取发票 / 收据

## 11. 阶段 10 — 结算

详见 [11_settlement_and_payment.md](11_settlement_and_payment.md)。

| 模式 | 关单触发 |
| --- | --- |
| 现付 | 离店当晚 |
| 预付 | 出单时 |
| 月结 (BTA / Direct Bill) | 月底对账后 |
| 信用住 / 信用卡 | 离店后 24–72h 实扣 |

## 12. 阶段 11 — 报销

- 出行人提交：发票 / 行程单 / 酒店账单
- 系统自动比对：发票抬头 / 税号 / 金额 / 内容
- 拒绝项：私人杂费、含早超份、未授权升房、迷你吧
- 详见 [14_reimbursement_compliance.md](14_reimbursement_compliance.md)

## 13. 阶段 12 — 关单与归档

| 字段 | 含义 |
| --- | --- |
| `closed_at` | 关单时间 |
| `closed_by` | 关单人 |
| `final_amount` | 最终金额 |
| `discrepancy` | 差异（出单 vs 离店 vs 发票） |
| `feedback_score` | 客户评分 |
| `audit_trail` | 全过程审计 |

> 客户评分 ≤3 / 5 应自动触发"客诉处理 SOP"（[15_complaint_handling_sop.md](15_complaint_handling_sop.md)）。

## 14. 风险点速查

| 风险 | 防护 |
| --- | --- |
| 双订 | 出单前查询近 30 天同员工同日期同城市订单 |
| 价格滞后 | 出单前重新询价（30 秒内有效） |
| 房型错位 | 内部映射确保 `internal_room_class` 一致 |
| 担保过期 | 信用卡 6 个月以上自动重新校验 CVC |
| 政策违规 | 校验链路前置 + 后置二次复审 |
| 数据隐私 | 出行人身份信息加密存储（见 [19_compliance_privacy_security.md](19_compliance_privacy_security.md)） |
| 渠道砍单 | 监控 `external_confirmation_no` 状态变更，5 分钟内响应 |
| 多人合订 | 房型容量校验 + 双向 acknowledgement |

## 15. 通用检查清单（差旅运营人员）

```
[ ] 出行人身份齐全
[ ] 入住 / 离店日期、城市、入住人数核对
[ ] 房型、床型、含早、加床
[ ] 价格合理（差标内 / 已审批）
[ ] 取消政策记录到工单
[ ] 担保方式正确，公司挂账已与酒店确认
[ ] 出单确认号、PMS Reservation ID 双向收到
[ ] 通知出行人、主管、酒店
[ ] T-24h 复核
[ ] 入住后联络（仅 VIP / 重要客户）
[ ] 离店复核账单
[ ] 报销提交
[ ] 关单 + 满意度
```
