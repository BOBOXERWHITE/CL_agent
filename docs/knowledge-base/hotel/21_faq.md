# 21 FAQ — 高频问答

#### 关键词
`FAQ / 常见问题 / 取消 / 改签 / 发票 / 报销 / 含早 / 押金 / 信用卡 / 协议价 / 会员 / 升级 / Walk / 投诉 / 国际差旅`

> 本 FAQ 用问答形式编排，便于 RAG 检索。每个 Q/A 自闭环，必要时引用其它章节。

## 1. 预订相关

### Q1.1 公司协议价怎么找不到？
A：先核对：
1. 你登陆的是公司 OBT / TMC，而不是公开 OTA
2. 该酒店是否在公司协议名单内（差旅平台 → 酒店详情有"协议"标记）
3. 入住日期是否在协议有效期内
4. 当日是否为节假日（部分协议节假日不可用）
5. 房型是否在协议覆盖范围内
若以上都符合仍找不到，请联系采购更新 Rate Loading。详见 [10](10_corporate_rate_contract_sop.md)。

### Q1.2 同一酒店为什么 OTA 比直连便宜？
A：常见原因：
1. OTA 自营促销（占比成本）
2. 价格平价漂移（Rate Parity 失效）
3. 你看的是 OTA 不可退、直连可退价
4. 渠道差异（含早 / 不含早）
若价格 + 政策 + 房型 完全一致，可走"价格保证"申诉，详见 [04](04_rate_plans_and_fees.md#价格保护-best-rate-guarantee)。

### Q1.3 我有信用卡，可以不付押金吗？
A：多数协议公司 + 信用卡担保下，仅冻结预授权（USD 50–200 / 晚 或 RMB 200–2000 / 段），不实际扣款。具体见 [11](11_settlement_and_payment.md)。

### Q1.4 同行同住怎么订？
A：差旅平台需启用"同行同住"工单：
1. 选 1 间双床房 (TWN)
2. 录入 2 位入住人
3. 系统按差标分摊（部分公司允许）
4. 同部门同性别多数允许，异性 / 跨部门视政策

### Q1.5 加床多少钱？
A：视酒店：
- 经济型：免费或 RMB 100–200 / 晚
- 中端：RMB 200–400
- 高端：RMB 400–800
- 套房 / 大床房：可加 1 张
- 部分酒店仅提供婴儿床免费

### Q1.6 含早是几份？
A：默认 = 入住成人数（≤2）。订双床房通常含 2 份双早；订单床房含 1 份。具体看 `breakfast_count` 字段。

### Q1.7 早餐儿童免费吗？
A：常见：
- 6 岁以下免费
- 7–12 岁半价或 1 份免费
- 12 岁以上视为成人
具体逐酒店配置，差旅平台从 PMS / OTA 同步。

### Q1.8 我能订非协议酒店吗？
A：视公司差旅政策：
- 部分公司"必须协议酒店"
- 部分公司"协议优先 + 例外申请"
- 部分公司"自由选 + 报销时校验"
详见 [14](14_reimbursement_compliance.md)。

## 2. 改签 / 取消

### Q2.1 我能否在最后一刻取消？
A：取决于价格码的 `cancel_policy`：
- BAR + 24h 免费 → 入住前 ≥24h 全退
- 早鸟 / 不可退 → 全损
- 协议价 → 多数 6PM 当日免费
具体见订单详情中的"最迟可免费取消时刻"。

### Q2.2 入住当天能改日期吗？
A：多数渠道支持，但取消旧 + 新订当下 BAR：
- 旧订单按取消政策（通常入住当天收费）
- 新订单按当下 BAR
若你只是延 1–2 晚，到酒店前台续住通常更划算。

### Q2.3 不可退订单能申请退款吗？
A：常规渠道不能；走"善意退款"（Goodwill）通常需要：
- 不可抗力（地震、疫情、签证拒签）
- 健康事由（住院）
- 公务变更（紧急任务）
- 高级会员（金 / 钛 / 钻石）
申诉流程见 [07](07_modification_cancellation_sop.md#申诉成功的常见前提)。

### Q2.4 退款多久到账？
A：
- 微信 / 支付宝：0–24h
- 国内信用卡：7–15 工作日
- 海外信用卡：5–30 工作日
- 月结挂账：月结对账时冲销
详见 [11](11_settlement_and_payment.md#退款时效)。

### Q2.5 改名怎么办？
A：同部门内多数允许免费改名；跨公司视为重订。需联络 TMC + 酒店双向确认。

## 3. 入住

### Q3.1 我能否提前入住？
A：
- 标准入住时间：14:00 / 15:00
- 高级会员：保证 16:00 退房，但提前入住"基于可用性"
- 部分酒店：早入收半天费
- 24h Your24 (Marriott Ambassador)：任意 24 小时

### Q3.2 飞机晚点凌晨才到，怎么办？
A：必须有担保（信用卡 / 公司挂账），并在出单时设置 ETA。即使凌晨抵达，房间会保留至次日 06:00。详见 [08](08_noshow_earlycheckout_latecheckin_sop.md)。

### Q3.3 现场要加价怎么办？
A：拒绝。你已付款 / 已担保订单不可加价。立即联络 TMC + 出示原确认号。若酒店仍坚持，要求看到酒店书面"超售通知"。

### Q3.4 房间不满意能换吗？
A：
- 噪音 / 异味 / 故障 → 免费换
- 楼层 / 朝向不喜欢 → 视酒店（多数允许 1 次）
- 想升级 → 视会员等级 / 自费

### Q3.5 行李能存吗？
A：所有正规酒店均提供免费行李寄存（≤24h 或离店当日）。

## 4. 离店

### Q4.1 几点退房？
A：
- 标准：12:00
- 银卡：13:00
- 金卡：14:00
- 白金 / 钻石：16:00
- 提前请求 18:00 视酒店

### Q4.2 押金多久退？
A：
- 现金：当场
- 信用卡冻结：7–30 天自动释放（部分银行 60 天）
- 杂费扣减后差额：3–7 工作日

### Q4.3 离店时账单不对怎么办？
A：当场核对每一项。常见错收：
- 含早被错收早餐费
- 协议外杂费（迷你吧 / 电影）
- 隔壁房杂费串单
- 双重扣款
当场拒签 + 让 Front Office Manager 修正。

## 5. 发票与报销

### Q5.1 发票必须公司抬头吗？
A：是。除非你是个人 + 不报销。公司报销必须含"公司全称 + 税号"。详见 [12](12_invoicing_tax_china.md)。

### Q5.2 发票项目能写"会议费"吗？
A：差旅政策建议为"住宿费"。"会议费"可能影响进项税抵扣或被财务拒收。

### Q5.3 含早发票能抵扣吗？
A：不能。餐饮服务列入禁止抵扣范围（见 [12](12_invoicing_tax_china.md#不可抵扣)），即使开了专票，餐饮部分也不能抵扣进项税。建议要求酒店分开开票。

### Q5.4 跨年发票能报销吗？
A：上一年度的差旅发票需在次年 5 月 31 日前清账。具体看公司财务时效。

### Q5.5 海外发票能抵扣吗？
A：海外发票不能抵扣中国境内增值税。但可作为差旅费记账凭证（人民币入账）。

### Q5.6 数电票还能报销吗？
A：能。数电票与纸质发票具有同等法律效力。差旅平台支持自动验真。

### Q5.7 普票能报销吗？
A：能。但普票不能抵扣进项税。若有专票选项，财务一般要求专票。

## 6. 协议价 / 会员

### Q6.1 协议价 vs 会员价哪个低？
A：通常协议价更低（公司谈判筹码）。但部分集团会员促销（如年中大促）会低于协议价。差旅平台应自动展示"两者最低"。

### Q6.2 我能在协议价订单中累积积分吗？
A：多数集团允许：
- Marriott / Hilton / IHG / Hyatt / Accor：协议价单仍可绑会员账号 + 积分
- 但部分协议（深度折扣）会限制升级 / 行政酒廊礼遇

### Q6.3 高级会员升级一定能拿到套房吗？
A：仅 Hyatt Globalist 有"标准套房升级保证"，其它集团均"基于可用性"。

### Q6.4 我的积分归我还是公司？
A：视公司政策：
- 多数外企：归个人（差旅福利）
- 多数国企 / 央企：归公司
- 中型企业：可配置

### Q6.5 跨集团状态匹配怎么做？
A：Hyatt 持续提供 Status Match (持其他集团高级状态可申请 Hyatt 一年 Globalist 挑战)。其他集团偶尔提供。

## 7. 国际差旅

### Q7.1 海外酒店怎么付款？
A：推荐：
- 公司 BTA / Lodge Card（Amex / Visa Commercial）
- 虚拟卡 (VCC)
- 个人信用卡（后续报销）
不建议现金。

### Q7.2 DCC 是什么？要选吗？
A：Dynamic Currency Conversion（动态货币转换）。POS 询问"以本币 (RMB) 还是当地币 (USD) 结算"。**永远选当地币**，DCC 加价 1–10%。

### Q7.3 海外酒店 Resort Fee 必须付吗？
A：是的。Resort Fee 是强制项，OTA 显示价不含。差旅平台应在卡片显示 `mandatory_surcharges`。

### Q7.4 外籍员工入住中国大陆需要什么？
A：
- 涉外资质酒店
- 护照原件 + 签证
- 入住后 24h 内公安备案（酒店操作）
- 差旅平台预订时需勾选"外籍"标志，否则订单可能失败

### Q7.5 我在迪拜住的酒店能开 VAT 发票退税吗？
A：阿联酋住宿 VAT (5%) 不退。但商品 VAT 在出境前可办退税。商务 VAT 退税通过第三方机构申请，周期 6–12 月。

## 8. 客诉

### Q8.1 我被 Walk 了怎么办？
A：详细见 [09](09_overbooking_walk_relocation_sop.md)。简要：
1. 索取 Walk Notice 书面凭证
2. 联络 TMC 24/7
3. 要求同档以上酒店 ≤3km
4. 第一晚全免 + 双向交通
5. 关单后填客诉

### Q8.2 半夜被吵怎么办？
A：
1. 立即拨打前台
2. 不解决要求换房
3. 仍不解决要求 Front Office Manager 现场处理
4. 离店时要求当晚房费补偿（多数酒店给 50% 或换房 + 致歉）
5. 关单后填客诉

### Q8.3 物品丢失怎么办？
A：
1. 立即报失（前台 + 当地警方）
2. 索要警方报案号
3. 酒店保险覆盖（视物品 + 价值）
4. 公司差旅险补充覆盖
5. 个人物品险（自费）兜底

### Q8.4 食物中毒怎么办？
A：
1. 立即就医（120 / 当地紧急号码）
2. 通知 TMC + 集团客服
3. 保留就诊证明、检测报告
4. 申请：医疗 + 滞留 + 差旅延伸费用
5. 严重者走法律 / 集团赔偿
详见 [16](16_force_majeure_sop.md)。

## 9. 政策

### Q9.1 我超差标怎么办？
A：根据超额比例：
- ≤10%：自助提交说明
- 11–30%：主管审批
- >30%：HR / VP 审批
+ 超额自付（差额从工资扣 / 不予报销）。

### Q9.2 周末入住公司允许吗？
A：取决于公司政策。多数允许：
- 周日入住、周一会议（避免一早赶路）
- 周一离店但已订周日（视为合理）
不允许：
- 周五–周日仅旅游意义入住

### Q9.3 客户接待算差旅吗？
A：不算。客户接待 → "业务招待费"，差旅 → "差旅费"。两者会计科目、扣除限额不同。详见 [14](14_reimbursement_compliance.md#业务招待费-vs-差旅费)。

### Q9.4 节假日加价能否报销？
A：以差标决定。差标内合规。差标外按超标流程。

## 10. 数据 / 安全

### Q10.1 差旅平台会保存我的护照号吗？
A：会，但 AES-256 加密存储，脱敏返回。仅入住核验时还原。详见 [19](19_compliance_privacy_security.md)。

### Q10.2 我的差旅数据会发给海外吗？
A：海外差旅订单会传给海外酒店 PMS / 集团 CRS，属"必要的合同履行"，已通过 SCC + 单独同意。详见 [19](19_compliance_privacy_security.md#跨境数据传输)。

### Q10.3 我能下载我的所有差旅数据吗？
A：能。数据可携带权（PIPL 第 45 条 / GDPR 第 20 条）。在差旅平台个人中心提交请求，30 日内响应。

### Q10.4 我离职后数据保留多久？
A：
- 业务必需（财务 / 审计）：≥10 年
- 个人偏好 / 历史订单：30 日内删除（除非业务必需）
具体见公司隐私政策。
