# 11 结算与支付

#### 关键词
`结算 / 支付 / 现付 / 预付 / 月结 / Direct Bill / BTA / Lodge Card / VCC / Virtual Credit Card / 信用卡 / 押金 / 预授权 / 退款 / 拒付 / Chargeback / 月对账`

## 1. 支付与结算的层次

```
[1] 担保 (Guarantee)            ← 预订时
[2] 预授权 (Pre-Authorization)  ← 入住时
[3] 实际扣款 (Actual Charge)    ← 退房时 / 月结时
[4] 退款 (Refund)               ← 取消 / 早离 / 客诉
[5] 月对账 (Reconciliation)     ← 月结
[6] 财务核销 (Settlement)       ← 月对账后
```

## 2. 担保方式与风险归属

| 担保方式 | 出行人责任 | 公司责任 | 适用场景 |
| --- | --- | --- | --- |
| 个人信用卡 | 全责 | 仅协议责 | 散客 + 后续报销 |
| 公司 BTA / Lodge Card | 0 | 全责 | 大企业 |
| 虚拟卡 (VCC) | 0 | 全责（一次性） | 单次 / 高安全 |
| Direct Bill (月结挂账) | 0 | 全责 | 协议酒店 |
| 现金 | 全责 | 0 | 经济型 / 应急 |
| 信用住 (芝麻 / 微信支付分) | 全责 | 协议责 | 国内散订 |

## 3. 现付 vs 预付

| 维度 | 现付 (Pay-at-Hotel) | 预付 (Prepay) |
| --- | --- | --- |
| 收款方 | 酒店 | OTA / 集团 |
| 收款时点 | 入住 / 离店 | 出单时 |
| 取消政策 | 通常更宽松 | 通常更严 |
| 价格 | 普遍偏高 | 普遍偏低 |
| 发票 | 酒店开 | OTA / 酒店开 |
| 适用 | 协议公司 / 月结 | 散客 / 不可退促销 |

## 4. 预授权 (Pre-Authorization)

### 4.1 用途

- 杂费押金（迷你吧、电话、洗衣）
- 房费押金（部分酒店）
- 损坏押金
- 签证 / 身份核验

### 4.2 释放时效

| 银行 / 卡组织 | 自动释放 |
| --- | --- |
| Visa | 7–30 天 |
| Mastercard | 7–30 天 |
| Amex | 7–30 天 |
| UnionPay (银联) | 3–15 天 |
| Discover / JCB | 7–30 天 |
| 国内借记卡 | 1–7 天 |
| 香港 / 日本本地卡 | 30–60 天 |

### 4.3 预授权金额参考

见 [04_rate_plans_and_fees.md](04_rate_plans_and_fees.md#信用卡冻结金额-pre-auth)。

## 5. 月结 (Direct Bill / BTA)

### 5.1 启用前提

```
- 与酒店 / 集团签订协议（含 Direct Bill 条款）
- 公司提交营业执照、信用资质、银行账户、税号
- 酒店申请并核准信用额度
- 双方约定账期（30 / 45 / 60 天）
```

### 5.2 月结流程

```
[每月 1 日]   酒店 / 集团出账（上月入住数据）
[2–5 日]      公司财务下载账单 + 比对内部订单
[5–10 日]     差异核对（漏 / 错 / 重）
[10–15 日]    确认账单 → 开发票
[15–25 日]    付款（按账期）
[25 日后]     交易关闭
```

### 5.3 对账文件格式

| 字段 | 含义 |
| --- | --- |
| `confirmation_no` | 确认号 |
| `pms_reservation_id` | PMS ID |
| `guest_name` | 入住人 |
| `cost_center` | 成本中心 |
| `project_code` | 项目 |
| `check_in / check_out` | 入住 / 离店 |
| `room_charge` | 房费 |
| `tax_amount` | 税 |
| `service_charge` | 服务费 |
| `incidentals` | 杂费 |
| `total_amount` | 合计 |
| `currency` | 币种 |
| `discrepancy_flag` | 差异标记 |

差旅平台必须提供"导出 Excel + 自动对账"功能。

## 6. 虚拟卡 (VCC)

### 6.1 优势

- 一次一卡：刷一次后失效
- 可设额度上限：刚好等于订单总额
- 可设有效期：覆盖入住区间
- 可设"仅限酒店 MCC 7011"
- 不暴露真实卡信息

### 6.2 主要发卡

| 服务商 | 国内 / 海外 |
| --- | --- |
| Conferma Pay | 海外（与 Amex GBT / BCD 集成） |
| eNett | 海外 |
| AirPlus | 海外 |
| WEX | 海外 |
| 招商银行差旅卡 | 国内 |
| 中信信银易付 | 国内 |
| 浦发银行公司卡 | 国内 |
| 平安虚拟卡 | 国内 |

### 6.3 VCC 集成要点

```
- 出单时调用 VCC 创建 API → 拿到 16 位虚拟卡 + 有效期 + CVV
- 把 VCC 提交给酒店（GDS / 直连 API / 邮件）
- 酒店预授权 + 实际扣款
- 离店后自动关闭 VCC
- 对账时凭 VCC 唯一卡号关联订单
```

## 7. BTA / Lodge Card

| 维度 | BTA (Business Travel Account) | Lodge Card |
| --- | --- | --- |
| 是否实体卡 | 否 | 否 |
| 限定使用 | 差旅公司 / GDS | 大型差旅公司 |
| 主要发卡 | Amex BTA、Diners、Visa Commercial | Amex Lodge |
| 集成 | TMC + GDS | TMC + GDS |
| 优点 | 集中对账、高额度 | 集中对账 |
| 缺点 | 需企业资信审核 | 仅特定 TMC |

## 8. 退款 (Refund)

### 8.1 退款类型

| 类型 | 触发 |
| --- | --- |
| 全额退款 | 取消在免费窗口内 |
| 部分退款 | 早离、半退政策、Walk 补偿 |
| 拒绝退款 | NRF + 不可豁免 |
| 善意退款 | 集团客服 / Goodwill |
| 拒付争议退款 | Chargeback 成功 |

### 8.2 退款时效（详见 [07](07_modification_cancellation_sop.md#退款时效)）

### 8.3 退款触发链

```
出行人提取消 → 系统调用渠道取消 →
渠道返回 cancel_confirmed →
财务系统创建 refund_intent →
原支付通道发起 refund →
通知出行人 / 财务 / 主管
```

## 9. Chargeback (信用卡拒付)

### 9.1 触发原因

- 客人争议（未入住、未授权、虚假交易）
- 服务严重未达标
- 卡被盗刷
- 双重扣款

### 9.2 流程

```
[1] 持卡人通过发卡行发起拒付（最长 120 天内）
[2] 发卡行通知收单行 / 商户（酒店 / OTA）
[3] 商户提交证据（入住凭证、签字、PMS folio）
[4] 卡组织裁决
[5] 持卡人胜：退款 + 商户损失 USD 25–50 拒付费
   商户胜：拒付驳回
```

### 9.3 商户证据

```
- 信用卡授权凭据 (CC Authorization)
- PMS Folio + 客人签字
- 身份证 / 护照复印件
- Email 沟通记录
- 取消 / 改签历史
- 其他相关凭证
```

## 10. 跨境支付与汇率

### 10.1 货币选择

| 支付币种 | 优势 | 劣势 |
| --- | --- | --- |
| 本币 (Local Currency) | 无 DCC 加价 | 收单行汇率 |
| 卡持有人币种 (DCC) | 提前可见汇率 | 加价 1–10% |

> 差旅政策应明确："优先选用本币结算，不使用 DCC"。

### 10.2 汇率锁定

- 预付订单：以预订时汇率锁定（部分平台）
- 现付订单：按入住 / 离店时汇率
- 多币种结算：BTA 通常以美元结算，对账时转换

### 10.3 跨境合规

- 国内出境差旅金额 / 笔数大：可能触发外管局监控
- 大额结算建议走对公电汇 (T/T)，不用个人信用卡
- 海外大额杂费（如度假村活动）建议在公司层级直接结算

## 11. 押金管理

| 类型 | 收取节点 | 退还 | 注意 |
| --- | --- | --- | --- |
| 房费押金 | 入住 | 离店 | 现金不便差旅 |
| 杂费押金 | 入住 | 离店 | RMB 500 国内常见 |
| 损坏押金 | 入住 | 离店 + N 日 | 度假村 / 公寓 |
| 信用卡冻结 | 入住 | 7–30 日 | 推荐 |

> **现金押金风险**：离店忘退现 / 多收 / 现金丢失。差旅政策应优先信用卡 / 公司 BTA。

| 项目 | 归属 |
| --- | --- |

## 13. 决策表（差旅团队）

| 场景 | 推荐支付方式 |
| --- | --- |
| 协议酒店 / 月结启用 | Direct Bill |
| 大企业全员 | BTA + VCC |
| 中型企业 | VCC + 个人卡报销 |
| 小型企业 | 个人卡报销 |
| 高风险海外目的地 | VCC（限额 + 限期） |
| 客户接待 / 客户支付 | Direct Bill / VCC |
| 不可退预付 | VCC |
| 长住公寓 | 月租合同 + 对公 T/T |

## 14. 风险点

1. **预授权未释放** → 员工额度被冻结，需主动联络银行
2. **DCC 默认勾选** → 多收 1–10%，明确告诉酒店"以本币结算"
3. **月结对账漏单** → 对账系统必须双向 hash 比对（订单 hash vs 酒店 folio hash）
4. **VCC 卡有效期短于实际入住** → 配置 VCC 时入住前 7 天 + 离店后 7 天为有效区间
5. **Chargeback 滥用** → 对协议酒店造成损失，差旅采购需主动监控
6. **跨境信用卡拒收** → 选择支持 Visa Commercial / Amex Corporate 的酒店
7. **押金不退** → 离店时必索取释放凭证
