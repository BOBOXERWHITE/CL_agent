# 12 中国境内税务与发票

#### 关键词
`增值税 / VAT / 专票 / 普票 / 数电票 / 全电发票 / 发票抬头 / 税号 / 税率 / 6% / 9% / 1% / 3% / 进项税 / 不得抵扣 / 税控盘 / 红字发票 / 发票作废 / 个人抬头 / 公司抬头 / 餐饮 / 住宿`

> 本文以中国境内（不含港澳台）法规为准，截至 2026-04 现行政策。具体业务以国家税务总局最新规定与企业财务部门要求为准。

## 1. 增值税基本框架

中国住宿服务属于"现代服务业 - 生活服务 - 住宿服务"，由 2016 年 5 月 1 日"营改增"统一纳入增值税范围。

| 纳税人类型 | 销售额 | 适用税率 | 计税方式 |
| --- | --- | --- | --- |
| 一般纳税人 | 年销售额 ≥500 万 | **6%** | 一般计税：销项 - 进项 |
| 小规模纳税人 | 年销售额 <500 万 | **3%**（疫情期间 1%；2027 年仍延续 1% 优惠） | 简易征收：直接 1% / 3% |
| 特殊行业 | — | — | — |
| 长期租赁（> 30 日） | — | **9%** | 不动产经营租赁 |

> 餐饮服务税率同样为 **6%**（一般纳税人）。住宿 + 餐饮分开开票时，可以分别 6%。
> 当含早 / 含餐捆绑销售时，建议要求酒店分开开票或在备注栏明确"住宿费 + 餐饮费"。

## 2. 发票类型

### 2.1 增值税专用发票（专票）

- 一般纳税人才可开具
- 购方为**一般纳税人**时可作为进项税抵扣凭证
- 信息要求：
  - 销售方：名称、税号（统一社会信用代码）、地址电话、开户行账号
  - 购买方：名称、税号、地址电话、开户行账号
  - 货物或应税劳务：项目名称、规格型号、数量、单价、金额、税率、税额
  - 备注栏：备注信息
  - 销售方盖章：发票专用章

### 2.2 增值税普通发票（普票）

- 任何纳税人均可开具
- **不可抵扣进项税**（仅可作为入账凭证）
- 信息要求基本同专票，但对购买方：
  - 公司抬头：必须含"名称 + 税号"
  - 个人抬头：仅需姓名（不含税号）

### 2.3 数电发票 / 全电发票（电子专票 / 电子普票）

- 自 2024 年全国推广，截至 2026 年绝大部分地区已全量切换到"数电票"
- 与纸票具有同等法律效力
- 通过"全国统一电子发票服务平台"开具
- 票样：
  - **发票号码**：20 位（代替原 12 位发票代码 + 8 位发票号码）
  - **税务 UKEY / 数字证书**已淘汰，改为"开票人身份认证"
  - 二维码可验真
- 邮箱投递 / 平台下载 PDF + OFD

### 2.4 不再使用的发票

- 增值税普通发票纸质（仍可使用，但比例下降）
- 卷式发票
- 通用机打发票（已停用）
- 旧版定额发票（部分小城市仍流通）

## 3. 发票抬头与税号要求

| 抬头 | 是否需税号 | 是否可专票 | 是否可抵扣 |
| --- | --- | --- | --- |
| 公司全称（一般纳税人） | 必填 | 是 | 是 |
| 公司全称（小规模） | 必填 | 极少 | 否 |
| 个人姓名 | 否 | 否 | 否 |
| 个体工商户 | 必填 | 视情况 | 部分 |

> 自 **2017 年 7 月 1 日**起，购买方为企业（公司、非企业性单位、个体工商户）的，索取增值税普通发票时，**必须提供纳税人识别号或统一社会信用代码**，否则发票不得作为税收凭证。

## 4. 住宿服务发票内容（项目名称）

发票"货物或应税劳务"栏目可填：

| 标准项目名 | 适用 |
| --- | --- |
| `*住宿服务*住宿费` | 标准住宿 |
| `*住宿服务*住宿费*会议费` | 会议入住 |
| `*现代服务*会议费` | 纯会议（非住宿） |
| `*餐饮服务*餐饮费` | 早餐 / 午餐 / 晚餐分开 |
| `*现代服务*商务服务费` | 商务中心服务 |
| `*文化体育服务*门票费` | 度假村门票 |
| `*生活服务*洗涤费` | 洗衣 |

> **报销关键**：差旅政策要求发票项目名必须为 `*住宿服务*住宿费`，不得为"会议费 / 培训费 / 服务费"等模糊项。

## 5. 进项税抵扣规则

### 5.1 可抵扣

- 纳税人因生产经营**外出住宿**取得的增值税专用发票
- 项目内容为"住宿费"（非餐饮、非娱乐）
- 取得专票
- 已认证（自 2017 年起改"勾选确认"）

### 5.2 不可抵扣

| 情形 | 原因 |
| --- | --- |
| 用于个人消费 / 福利 | 《增值税暂行条例》明确不得抵扣 |
| 用于免税项目 / 简易计税 | 不得抵扣 |
| 用于集体福利 / 个人消费 | 不得抵扣 |
| 餐饮服务 | 列入禁止抵扣范围（即使开专票，也**不可抵扣**） |
| 居民日常服务 / 娱乐服务 | 不可抵扣 |
| 普票 | 一律不可抵扣 |
| 货物已认证未抵扣超 360 天 | 失效 |

> **常见误区**：含早酒店开"住宿费 + 餐饮费"，餐饮费部分**不可抵扣进项税**。

## 6. 红字发票（冲红 / 退款）

| 场景 | 处理 |
| --- | --- |
| 客户取消订单 → 退款 | 销售方开红字发票冲销原蓝字发票 |
| 服务质量问题 → 部分退款 | 部分红冲 |
| 发票抬头错误 → 重开 | 红冲 + 新开 |
| 跨月发现问题 | 必须红冲（不可作废） |
| 当月发现问题 | 可作废（数电票直接红冲） |

数电票流程：

```
1. 销售方在电子发票服务平台填《开具红字增值税电子发票确认单》
2. 购买方接收并确认
3. 红字发票自动开出，与原蓝字关联
4. 进项税自动调整
```

## 7. 节假日 / 特殊场景

| 场景 | 注意 |
| --- | --- |
| 春节 / 国庆 + 婚礼酒店 | 部分餐饮无法开 6% 专票（涉及娱乐套餐） |
| 度假村全包 | 必要求拆分"住宿 / 餐饮 / 文化娱乐" |
| 套餐价 + 含 SPA | SPA 属于"生活服务-居民日常服务"，6% 但**不可抵扣** |
| 套餐价 + 含旅游门票 | 6% 文化体育服务 |
| 团建 / 培训 | 培训费可能为"现代服务-鉴证咨询" |
| 客户接待 | 列入"业务招待费"，受 60% / 0.5% 营收限额 |

## 8. 业务招待费 vs 差旅费

| 类型 | 含义 | 税务处理 |
| --- | --- | --- |
| 差旅费 | 因公出差 | 全额扣除企业所得税 |
| 业务招待费 | 接待客户 | 60% 扣除，且 ≤当年营收 0.5% |
| 会议费 | 真实会议 | 全额扣除 |
| 福利费 | 员工福利 | 14% 工资总额限额 |

> 差旅政策应严格区分，避免"业务招待"被混入"差旅"。

## 9. 发票时效

| 阶段 | 时限 |
| --- | --- |
| 销售方开票 | 离店当日 / 月结时 |
| 客户索取期限 | 发票开具后 30 天 |
| 进项税勾选确认期限 | **任意时点**（自 2020 年起取消 360 天限制） |
| 红字流程 | 60 天内 |
| 报销提交 | 视公司政策（多数 30 / 60 天内） |

## 10. 国内 OTA 发票场景

| OTA | 谁开票 | 项目 |
| --- | --- | --- |
| 携程现付 | 酒店 | `*住宿服务*住宿费` |
| 携程预付（部分 Merchant） | 携程 | `*现代服务*商务服务费` 或"代订住宿费" |
| 携程协议（B2B） | 携程开票 + 酒店 folio | `*住宿服务*住宿费` |
| 美团预付 | 美团（北京美团网络科技） | 平台代订发票 |
| 美团协议 | 协议主体开票 |  |
| 飞猪信用住 | 酒店 | 酒店开 |
| Booking.com 预付 | 酒店 | 酒店开（境内） / 海外开 |
| Agoda | Agoda 香港 | 海外发票（不可抵扣进项） |
| 直连酒店 | 酒店 | `*住宿服务*住宿费` |

> **重要**：OTA 平台发票项目若为"商务服务费 / 服务费 / 代订费"，部分财务系统**不视为差旅住宿费**，建议要求 OTA 单独提供"酒店原始 folio"作为附件。

## 11. 发票合规校验（差旅平台风控）

差旅平台报销审核应自动校验：

```
[必校]
- 抬头与公司全称完全一致（含"有限公司 / 股份"等后缀）
- 税号正确（18 位统一社会信用代码 / 旧 15 位税号）
- 发票号码 + 校验码可在国家税务总局"全国增值税发票查验平台"验真
- 票面金额与订单金额一致（误差 ≤2 元）
- 项目名 = `*住宿服务*住宿费` 或差旅政策允许项
- 开票日期 ≤ 离店日期 + 30 天
- 销售方 = 合同酒店 / 合同 OTA

[警示]
- 同一发票号码多次报销（重复）
- 发票抬头与税号不匹配
- 服务期与入住期不符
- 大额发票（> RMB 5,000）
- 跨年发票（次年 5 月 31 日前可报销当年差旅费）
```

## 12. 海外人员入境差旅

| 情形 | 发票处理 |
| --- | --- |
| 中国公司接待外宾住宿 | 中国境内酒店开境内发票 → 中国公司入账 |
| 中国公司海外子公司差旅 | 视目的国本地税务，不属于本节 |
| 香港 / 澳门 / 台湾差旅 | 视为出境差旅，发票为"收据 / VAT Invoice" |

## 13. 普票 vs 专票决策表（差旅）

| 场景 | 推荐 |
| --- | --- |
| 一般纳税人 + 月结 + 协议酒店 | **专票** |
| 一般纳税人 + 散订 + 报销 | **专票** |
| 一般纳税人 + 餐饮 / SPA | 普票（专票也不可抵扣） |
| 小规模 + 任何场景 | 普票（专票收益少） |
| 个人差旅 | 普票（公司抬头） |
| 公司报销但开个人抬头 | **拒收**（不合规） |

## 14. 实务建议

1. **入住时主动提供税号**：避免离店后还需返工
2. **协议酒店把税号写入 PMS 客户档案**：长期免重复
3. **离店前核对**：抬头、税号、项目、金额、税率
4. **数电票邮箱通讯录**：差旅人或财务统一收
5. **不接受"代开"票**：风险高
6. **不接受"机打 / 卷式"**：不符合现行规范
7. **拍照留底**：发票丢失成本高
8. **跨年票 5 月 31 日前清账**
