# 15 客诉与争议处理 SOP

#### 关键词
`客诉 / 投诉 / 服务补救 / 争议 / Service Recovery / Goodwill / 补偿 / 申诉 / Chargeback / 客户满意度 / NPS / 升级处理 / 礼宾经理 / GM`

## 1. 客诉分级

| 等级 | 标准 | 响应时效 | 决策权 |
| --- | --- | --- | --- |
| L1 轻微 | 房型不满意 / 含早差错 / 设施小故障 | 2h | 一线客服 |
| L2 一般 | 重复扣款 / 早离争议 / 房间噪音 | 1h | 一线客服 → 上级 |
| L3 严重 | Walk / 重大服务事故 / 安全 | 30 min | 主管 + 酒店总经理 |
| L4 极严重 | 人身安全 / 健康事件 / 重大投诉媒体 | 即时 | 总监 + 集团客服 |

## 2. 处理流程

```
[1] 接报          ← 多渠道：电话 / 工单 / 邮件 / IM
[2] 分级          ← 系统自动 + 人工复审
[3] 安抚          ← 共情 + 立即措施
[4] 调查          ← 事实链 + 证据
[5] 决策补偿      ← 补偿矩阵
[6] 执行          ← 退款 / 重订 / 升级 / 道歉
[7] 关单          ← 回访 + 满意度
[8] 复盘          ← 月度 / 季度
```

### 2.1 接报

| 渠道 | 时效 |
| --- | --- |
| TMC 24/7 热线 | 立即接通 |
| 飞书 / 钉钉机器人 | 5 min 内 |
| 工单（OBT） | 工时内 30 min |
| 邮件 | 1 工时 |

### 2.2 安抚（话术模板）

```
"非常感谢您及时反馈。我能理解您此刻的感受，这确实超出了我们和合作酒店应有的服务标准。
我会立刻为您处理 [具体动作]，预计在 [时间] 内给您答复。
为避免影响您的行程，请允许我先 [立即措施：换房 / 改签 / 备用酒店]。
我的工号是 [XXX]，您可以随时联络我。"
```

### 2.3 事实调查

| 必采证据 | 来源 |
| --- | --- |
| 订单详情 | 差旅系统 |
| PMS 入住记录 | 酒店 |
| 通话录音 | TMC |
| 邮件 / IM 记录 | OA |
| 现场照片 / 视频 | 客户 |
| 监控录像 | 酒店（敏感） |
| 第三方证据 | 警方 / 医院 |

## 3. 补偿矩阵

| 客诉类型 | 损失 | 补偿组合 |
| --- | --- | --- |
| 含早差错 | RMB 100 | 退含早费 + 50 餐饮券 |
| 房间设施故障 | 0–500 | 升级 / 50% 房费 / 1,000 集团积分 |
| 噪音 / 异味 | 500 | 换房 + 50% 房费 + 致歉信 |
| 重复扣款 | 全额 | 立即退 + 致歉 |
| 早离误算 | 1 晚房费 | 退误算金额 + 致歉 |
| Walk + 同档酒店 | 1 晚房费 | 详见 [09_overbooking_walk_relocation_sop.md](09_overbooking_walk_relocation_sop.md) |
| Walk + 降档 | 全程房费 | 全退 + 升级券 + 50,000 集团积分 |
| 服务严重失当 | 全程房费 | 全退 + GM 致歉 + 100,000 积分 + 礼宾经理跟进 |
| 安全事件 | 不可估 | 走法律 + 客户专属 + GM 致歉 |
| 食物中毒 | 医疗 | 全退 + 全部医疗 + 集团赔偿（视事实） |
| 物品丢失 | 物价 | 视酒店保险 + 集团赔偿 |

## 4. 服务补救权限矩阵

| 角色 | 现金 / 退款 | 升房 | 积分 | 致歉信 |
| --- | --- | --- | --- | --- |
| 一线客服 | ≤RMB 200 | 同价升房 | ≤10,000 | 模板信 |
| 主管 | ≤RMB 500 | 同档升档 | ≤30,000 | 主管签名信 |
| 客服总监 | ≤RMB 2,000 | 任意升级 | ≤80,000 | 总监签名信 |
| 副总 / GM | 任意 | 任意 | 任意 | GM 亲笔信 |

## 5. Chargeback 客诉

详见 [11_settlement_and_payment.md#chargeback-信用卡拒付](11_settlement_and_payment.md#chargeback-信用卡拒付)。

差旅平台触发 Chargeback 时：

```
[1] 立即通知酒店 / OTA 提供完整证据
[2] 内部审核：客诉是否属实
[3] 若属实 → 不抗辩，主动退款
[4] 若不属实 → 提交证据抗辩
[5] 卡组织裁决（30–90 日）
[6] 不论结果，更新客户档案
```

## 6. 客诉数据看板

```
1. 客诉数 / 总订单
2. 客诉分级分布
3. 各 SLA 达成率
4. 各酒店客诉率（年度 RFP 输入）
5. 各 OTA / 渠道客诉率
6. 客诉解决时长（中位 / P95）
7. 客诉再投诉率
8. 客户满意度（解决后回访）
9. 补偿支出
10. 主要原因分布（Walk / 设施 / 服务 / 价格）
```

## 7. 关单与回访

```
[关单后 24h]   电话 / 短信 / 邮件回访
[关单后 7 日]  推送满意度调查
[关单后 30 日]  补偿券 / 积分到账核对
```

满意度评分 ≤3 / 5 → 重新激活客诉，升级一级处理。

## 8. 防御性话术

### 8.1 客户情绪激烈

```
"非常理解您此刻的感受。
此事确实严重，超出我个人职权。
我已经升级给我的主管 / 客服总监，
预计在 [N 分钟] 内主动联络您。
您可以同时拨打 [GM 直拨电话 / 集团总部投诉热线]。"
```

### 8.2 客户要求过分（无法兑现）

```
"您的诉求我已经记录，会向集团客服正式提交申请。
集团裁决一般 [3 工作日] 内反馈，
在此期间我先做 [可行动作] 减轻您的损失。"
```

### 8.3 拒赔决策

```
"基于以下事实，我们无法支持您的赔偿诉求：
[1] [事实 1]
[2] [事实 2]
[3] 协议条款 [X] 项
我们将免去 [可豁免项目]，并赠 [积分券] 作为善意补偿。
若您不接受，可走 [集团客服 / 监管 / 仲裁] 渠道。"
```
