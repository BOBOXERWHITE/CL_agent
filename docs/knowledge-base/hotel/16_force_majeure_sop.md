# 16 不可抗力 / 应急 SOP

#### 关键词
`不可抗力 / Force Majeure / 自然灾害 / 疫情 / 战争 / 罢工 / 政府禁令 / 紧急疏散 / 安全 / 应急 / SOS / Travel Risk / 24/7 协助`

## 1. 不可抗力的范围（Industry Standard）

```
- 自然灾害：地震、洪水、台风、龙卷风、火山、海啸、严寒
- 公共卫生：传染病、检疫、疫苗强制
- 战争 / 暴乱：内战、恐袭、政变
- 政府禁令：禁飞、关闭机场 / 边境、交通管制
- 罢工 / 运输中断：航司罢工、地勤罢工、港口封闭
- 大型事故：火灾、爆炸、管道泄漏、停电
- 其他：通信中断、网络封闭、电信故障
```

## 2. 应急响应优先级

```
P0 — 出行人安全 (人身、健康、生命)
P1 — 出行人疏散 / 转移
P2 — 财产 / 行李 / 个人证件
P3 — 行程恢复 / 替代方案
P4 — 财务损失 / 报销 / 申诉
```

## 4. 出行人安全 SOP

### 4.1 出发前

```
[1] 目的地风控等级评估（GeoEye Risk / Riskline / 国际 SOS / iJET）
[2] 高风险目的地：需事前安全简报
[3] 极高风险：禁止 / 需 SVP 审批
[4] 全员投保差旅险
[5] 注册中国领事保护"外交部 12308"
[6] 留底护照、签证、应急联系人
[7] 配备国际漫游 / WhatsApp / 微信 海外通
```

### 4.2 出行中突发

```
[1] 立即报平安：飞书 / 钉钉 / 微信
[2] 联络 TMC 24/7
[3] TMC 评估等级 → 启动相应预案
[4] 出行人就近避险
[5] 公司联络中心实时跟进
[6] 必要时启动疏散
```

### 4.3 极端情形

| 情形 | 第一动作 |
| --- | --- |
| 火灾 | 立即撤离至 Assembly Point |
| 地震 | "蹲下 / 掩护 / 抓牢"，平静后撤离 |
| 武装袭击 | "Run-Hide-Fight" 原则 |
| 食物中毒 | 立即就医 + 告知 TMC |
| 重大疾病 | 立即就医 + 启动 SOS / 保险 |
| 失联 > 24h | 启动家属通知 + 警方报失踪 |
| 护照丢失 | 12308 + 当地中国使馆补办 |

## 5. 不可抗力下的差旅财务处理

### 5.1 取消 / 改签政策豁免

| 主体 | 默认豁免 | 申请方式 |
| --- | --- | --- |
| 集团（Marriott/Hilton/IHG/Hyatt/Accor） | 多数公开发布"Force Majeure Cancellation Policy" | 直接通过会员账户取消 |
| 国内 OTA | 视事件影响（民航局 / 国务院公告 + OTA 跟进） | 工单 + 政府公告附件 |
| 协议酒店 | 视年度合同条款 | 销售经理协助 |
| 批发商 | 较严，需逐单申诉 |  |
| TMC | 协助走集团 / 渠道 |  |

### 5.2 退款时效

```
正常情况：标准时效（详见 [11_settlement_and_payment.md])
不可抗力：退款时效可能延后（部分集团声明 60 工作日）
```

### 5.3 损失分摊

| 损失项 | 谁承担 |
| --- | --- |
| 已付不退房费 | 走差旅险 + 公司兜底 |
| 替代酒店费用 | 公司承担（公务） |
| 紧急医疗费 | 差旅险 + 公司兜底 |
| 出租 / 应急交通 | 公司承担 |
| 国际 SOS / 救援 | 保险 / 公司 |
| 滞留生活补贴 | 公司按目的地档发放 |
| 个人物品丢失 | 个人 + 行李险 |

## 6. 重大事件协调机制

```
内部建立"应急小组"：
- 行政 / HR  — 出行人联络
- 安全 / 风控 — 评估 + 决策
- 法务         — 合规
- 财务         — 兜底支付
- 公关 / 媒体  — 对外回应
- IT             — 通讯保障
```

### 6.1 例：H1 城市突发地震

```
[T+0]    地震警报 → 内部应急组启动
[T+1h]   全员清点：每位在 H1 的出行人状态
[T+2h]   联络酒店：是否安全 / 房屋是否受损
[T+3h]   启动 Plan B：附近安全酒店 / 撤离方案
[T+6h]   通讯：领事馆登记 / 家属通知
[T+12h]  分批撤离：包车 / 改签机票
[T+24h]  统计：人员 / 财物 / 损失
[T+72h]  财务申诉：差旅险 + 协议酒店豁免
[T+1w]   复盘 + 改进
```

## 9. 常见误解

1. **"不可抗力"不等于"任意豁免"**：仍需符合不可抗力构成要件（直接因果 + 不可预见 + 不可避免 + 不可克服）
2. **集团豁免函有效期短**：多数 Force Majeure Policy 仅覆盖事件爆发前后 7–30 天，超期需逐单申诉
3. **航班取消但酒店未取消**：若员工因航班无法抵酒店，部分酒店仍按 No-Show 收费，需主动出示航班行程单
4. **差旅险 60 天报销**：错过即丧失
5. **保险不赔擅自前往高风险区**：若公司禁去仍前往，保险拒赔
