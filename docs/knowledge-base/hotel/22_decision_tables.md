## 2. No-Show 决策表

| 输入 | 输出：处罚 | 输出：动作 |
| --- | --- | --- |
| 已担保 + 未通知 + 24:00 未到 | 全程房费 + 税 | 标记 No-Show，触发账务 |
| 已担保 + 提前通知 ETA 凌晨 | 0 | 房间保留至次日 06:00 |
| 不可抗力（航班 / 灾害） | 0（豁免，需证明） | TMC 申诉 |
| 健康（住院） | 0（豁免，需证明） | TMC 申诉 |
| 个人原因 | 全程房费 + 税 | 走超标自付 |
| 公务紧急变更 | 视酒店 | TMC 申诉 + 公司变更函 |

依据：[08](08_noshow_earlycheckout_latecheckin_sop.md)

## 4. Walk 决策表

| 情形 | 应得补偿 | 行动 |
| --- | --- | --- |
| 同档酒店 ≤3km | 第 1 晚全免 + 双向交通 + 致歉 | 接受 |
| 降档酒店 / >3km | 拒绝；要求升级方案 | 拒绝并升级 |
| 高级会员被 Walk | + 50,000–100,000 集团积分 + 升级券 | 索取书面 |
| 协议公司被 Walk | + 协议层级补偿 + RFP 备案 | 上报采购 |
| 凌晨被 Walk | + 双倍补偿 / 视情况 | TMC 升级 |

依据：[09](09_overbooking_walk_relocation_sop.md)

## 15. 技术决策（差旅平台开发）

| 场景 | 推荐 |
| --- | --- |
| 出单接口超时 | Idempotency-Key + 异步查询 |
| 并发改签 | 乐观锁（version） |
| 库存不一致 | 5 分钟同步 + 出单前重核 |
| 多渠道同酒店 | 去重 by `internal_hotel_id` |
| 多币种 | base_currency + display_currency + fx_at_booking |
| 信用卡 token | PCI 合规支付通道 |
| PII 加密 | AES-256 + KMS |
| 跨境数据 | SCC + 单独同意 |

依据：[18](18_data_integration_field_spec.md)、[19](19_compliance_privacy_security.md)

## 16. 高频问答速查（FAQ 摘要）

| 问 | 答 |
| --- | --- |
| 协议价找不到 | 检查 OBT + 日期 + 房型；联系采购 |
| 同行同住 | 走"同行同住"工单 + 双床房 |
| 含早份数 | 默认 = 入住成人数（≤2） |
| 早入早出 | 视会员等级 / 自费 |
| 现场加价 | 拒绝 + TMC 协助 |
| 押金多久退 | 现金当场 / 信用卡 7–30 天 |
| 含早能抵扣进项税 | 不能（餐饮不可抵） |
| DCC 怎么选 | 选当地币 |
| Resort Fee | 必付，OTA 不含 |
| 被 Walk | 索取书面 + 同档 ≤3km + 第 1 晚全免 |
| 半夜噪音 | 前台 → 换房 → 50% 房费补 |
| 不可退申诉 | 不可抗力 / 健康 / 公务 + 证明 |
| 海外护照丢 | 12308 + 使馆 |

依据：[21](21_faq.md)
